### Interface icons

- `circle.png` (the minimap dots), `next.png` (the arrow over the current target) and `shield.png`
  (the safe-zone badge) were drawn in code for this project on 2026-10-07 and are released under
  CC0 1.0 with the rest of the demo art.

### Equipment icons

- `Icons/Weapons/` and `Icons/Armor/` are rendered in-project from the demo's own equipment
  models with **Tools → Equipment Icon Generator**. They carry no attribution of their own
  beyond that of the models they are rendered from.

### Sign emblems

- `T_Emblem_Coins.png` is generated by the demo's editor tools — five struck coins, matching the diamond
  faces of the Fantasy Props MegaKit's own coin models. It exists because none of that pack's
  six sign emblems is a bank. Generated, not hand-painted, so it can be redrawn at any size;
  it carries no third-party attribution.

### Menu

- `OpenMMORPG-menu-background.jpg`, `OpenMMORPG-loading.jpg` and `OpenMMORPG-title.png` were
  generated with Google Gemini and are released under CC0 1.0 with the rest of the demo art
  (see `../CREDITS.md`).
- `MenuTitleBand.png` is generated by **Open MMORPG → Demo → Build Menu Stage** — an 8x128
  white strip whose alpha fades away top and bottom, tinted at runtime to make the scrim behind
  the title. Delete it and the next build writes it again.

### Footsteps

- `FootPrint.png`, `WaterRing.png` and `WaterDrop.png` are drawn by **Open MMORPG → Demo → Build Footstep
  Effects** from arithmetic (a boot sole, three concentric ripple crests, a round bead). Only drawn if missing,
  so a hand-made one at the same path is kept. They carry no third-party attribution.
