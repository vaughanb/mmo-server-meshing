# Add-on package

The Server Meshing add-on, test rig included, in the layout the
[Open MMORPG Addon Manager](https://github.com/open-mmorpg/open-mmorpg-addon-manager) expects. It is published from
[open-mmorpg-addons](https://github.com/open-mmorpg/open-mmorpg-addons), where `ServerMeshing/` is copied as it is here
(0.93.0 submitted for review in [open-mmorpg/open-mmorpg-addons#1](https://github.com/open-mmorpg/open-mmorpg-addons/pull/1));
this tree is where it is built.

```
ServerMeshing/README.md                              hand-written, shown on the repository page
ServerMeshing/dist/ServerMeshing.unitypackage        generated
ServerMeshing/dist/package.json                      generated
ServerMeshing/dist/screenshot.png                    generated by make-screenshots.py
```

`dist/` is the unit the Addon Manager reads: it fetches `package.json`, which names the `.unitypackage` to download and
the `screenshot.png` beside it.

## Rebuilding

The package and its manifest come from **Tools ▸ Open MMORPG ▸ Server Meshing ▸ Build Packages** in the editor, or in batch mode:

```
Unity.exe -batchmode -quit -projectPath <repo> -executeMethod MultiplayerARPG.MMO.Mesh.Editor.ServerMeshPackageBuilder.BuildAll
```

`Assets/ServerMeshing/Mesh/Editor/ServerMeshPackageBuilder.cs` holds the version, the update date, the guid, the
category and the description. The package carries an empty, extensionless file named after its guid — that is how the
Addon Manager recognises an installed add-on, so the guid must never change once published, and the marker and the
manifest's `guid` are written from the same constant so they cannot drift.

`python make-screenshots.py` redraws `screenshot.png`. The README is edited by hand.

## Before submitting

1. Check `packageUrl` in the manifest. It is built from `DistBaseUrl` in the builder and points at
   `open-mmorpg/open-mmorpg-addons`, so a release is published by copying `ServerMeshing/` there. The Addon Manager
   downloads the URL verbatim, so it has to resolve to the published `.unitypackage`.
2. Bump `Version` and `UpdateDate` in the builder, and rebuild.
3. Copy `ServerMeshing/` into the open-mmorpg-addons checkout and commit it there. A new add-on is listed once a
   maintainer adds its raw `package.json` URL to the Addon Manager's `manifest.json`.
