# Add-on packages

The two add-ons in the layout the [Open MMORPG Addon Manager](https://github.com/open-mmorpg/open-mmorpg-addon-manager)
expects, mirroring [open-mmorpg-addons](https://github.com/open-mmorpg/open-mmorpg-addons). Nothing here has been
submitted yet.

```
ServerMeshing/README.md                              hand-written, shown on the repository page
ServerMeshing/dist/ServerMeshing.unitypackage        generated
ServerMeshing/dist/package.json                      generated
ServerMeshing/dist/screenshot.png                    generated by make-screenshots.py
ServerMeshingTestRig/...                             the same, and it declares Server Meshing as a dependency
```

`dist/` is the unit the Addon Manager reads: it fetches `package.json`, which names the `.unitypackage` to download and
the `screenshot.png` beside it.

## Rebuilding

The packages and their manifests come from **Server Meshing ▸ Build Packages** in the editor, or in batch mode:

```
Unity.exe -batchmode -quit -projectPath <repo> -executeMethod MultiplayerARPG.MMO.Mesh.Editor.ServerMeshPackageBuilder.BuildAll
```

`Assets/ServerMeshing/Mesh/Editor/ServerMeshPackageBuilder.cs` holds the version, the update date, the guids, the
categories and the descriptions. Each package carries an empty, extensionless file named after its guid — that is how
the Addon Manager recognises an installed add-on, so a guid must never change once published, and the marker and the
manifest's `guid` are written from the same constant so they cannot drift.

`python make-screenshots.py` redraws the two `screenshot.png` diagrams. The READMEs are edited by hand.

## Before submitting

1. Check `packageUrl` in both manifests. It is built from `DistBaseUrl` in the builder and currently points at
   `vaughanb/mmo-server-meshing`; if these end up hosted in `open-mmorpg-addons` instead, change that constant and
   rebuild. The Addon Manager downloads the URL verbatim, so it has to resolve to the published `.unitypackage`.
2. Bump `Version` and `UpdateDate` in the builder, and rebuild.
3. Submission is manual: host `dist/` on a public GitHub repository and share the raw `package.json` URL on the
   Open MMORPG Discord. A maintainer adds it to the Addon Manager's `manifest.json`.
