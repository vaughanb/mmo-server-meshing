Lets the server stop sending movement states for characters seated in a vehicle. Nothing changes for a game that does not turn it on.

**Why.** The server's send loop writes every subscribed character's movement state to every player on every tick. For a character seated in a vehicle, that state carries nothing: every peer already puts a seated character on its seat each frame from the vehicle's passenger list (`BaseGameEntity.ApplyAuthoritativeLateUpdate`), and a new subscriber gets its position in the spawn message. In a game with crewed vehicles this is a large share of the downlink. Measured in one game: about 27 B a record with the kit's framing, 0.5-0.6 kB/s per seated character per player at the send rate it uses.

**The switch.** `BuiltInEntityMovementFunctions3D.SkipSeatedServerStates` (static, off by default). When on, `WriteServerState` returns false, writing nothing, for a seated character with no jump, dash or teleport pending. The send loop records only what was written, so a skipped character keeps its one-shot flags for the next tick that writes them. `CanWriteQuantizedServerState` follows the same rule, because the quantized send path never calls `WriteServerState`.

**The interpolation hold.** A client copy of a seated character holds its interpolation at the seat. Without it, a copy that saw the character before it boarded draws it back at that spot from the moment it leaves the seat until the exit teleport's state arrives. This applies whether the switch is on or not: a seated character is snapped to its seat every frame either way, so the hold changes nothing visible while it sits.

**Files.** `Core/Scripts/Gameplay/EntityMovementSystems/Implements/BuiltInEntityMovementFunctions3D.cs` only.

Tests in the game that runs it: the writes for a character seated or not, with each one-shot flag, the switch, the send loop's record, and the interpolation hold; and a two-client run in which an observer accepts no state while the character sits, and draws it standing where it stands within 0.5 m once it stands up.
